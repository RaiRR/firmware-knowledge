# firmware-knowledge
My personal roadmap and public lab for low-level engineering: UEFI/EDK II, C/C++/ASM, CPU architecture, firmware DevEx, and technical communication.

## 🎯 Learning Tracks

* **UEFI / EDK II (Core):** Deep dive into modern firmware development, debugging, and ecosystem architecture.
* **Low-Level Engineering:** Bare-metal C/C++, Assembly (ASM), and advanced system-level debugging techniques.
* **Architecture & Boot Flow:** Core and advanced concepts of x86_64 and ARM architectures, from reset vector to OS hand-off.
* **Automation & DevEx:** Python scripting, CI/CD pipelines for firmware validation, and custom developer tooling.
* **Public Portfolio:** Clear technical documentation, architecture diagrams, articles, and practical demo repos.
* **Technical Languages:** Maintaining English (EN) and French (FR), while actively expanding Technical Chinese (ZH) for hardware documentation and specs.
